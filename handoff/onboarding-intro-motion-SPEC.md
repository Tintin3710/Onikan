## 핵심 변경 요약
1. 인트로 그림 한 장(`intro-mascot.png`)을 **레이어 분리 일러스트**로 바꾸고, 진입 시 순서대로 움직인다: **노렌이 떨어져 흔들림 → 앞발이 노렌을 젖힘 → 사장님이 빼꼼 → 깜빡 → 말풍선 → 도장 쾅**.
2. 첫 실행(튜토리얼 미완료)은 **풀 버전**(버튼 활성까지 약 2.6초), 재방문은 **짧은 버전**(기존 1.8초 자동 이동 유지) 두 가지다.
3. 첫 실행은 말풍선 타이핑과 도장이 끝나야 "시작하기"가 나타난다(Duolingo식 대기). 화면을 탭하면 **바로 마지막 상태로 건너뛴다**.
4. 시퀀스가 끝나면 사장님은 **대기 루프**(숨쉬기·깜빡임·노렌 미세 흔들림)로 살아 있다.
5. 분기·타이머·중복 전환 방지 같은 **기존 로직은 바꾸지 않는다**. 바뀌는 건 그림 영역과 등장 타이밍뿐이다.
6. 네이티브 스플래시는 움직일 수 없으므로 **인트로의 0프레임**으로 만든다: 배경 `softer`로 통일, 이미지는 빈 캔버스, 인트로 그림이 준비된 뒤 닫는다(아래 "스플래시 연결").

## 스플래시 연결 (네이티브 스플래시 → 인트로)

현재(코드 확인 2026-11-15): `app.json` `splash` = `assets/splash.png`(1024², 사실상 빈 흰 이미지) + 배경 `#F2F2F4`, `resizeMode: contain`. 다크 값 없음. 코드에서 `preventAutoHideAsync`/`hideAsync` 호출 없음(자동 닫힘). → 인트로 캔버스 `#F5F5F5`와 색이 미세하게 다르고, 다크 모드에선 밝은 스플래시 → 어두운 인트로로 번쩍인다.

| # | 상황 | 동작 |
|---|---|---|
| 1 | 스플래시 배경 | 라이트 `#F5F5F5`(`softer`), 다크 `#131316`(`softer` 다크, `grey.g10`). `expo-splash-screen` 플러그인 설정에 `dark` 값 추가 |
| 2 | 스플래시 이미지 | **빈 캔버스**(투명 또는 배경색 단색). 로고·노렌을 넣지 않는다 — 인트로가 노렌을 위에서 떨어뜨리므로, 스플래시에 그림이 있으면 사라졌다 다시 나타나는 점프가 생긴다 |
| 3 | 닫는 시점 | 루트에서 `SplashScreen.preventAutoHideAsync()` → `IntroScreen`이 ① 설정 복원 완료 ② 레이어 첫 프레임 렌더(`onLayout`) 뒤 `hideAsync()` → 같은 프레임에 시퀀스 시작 |
| 4 | 안전장치 | 위 조건이 2,000ms 안에 안 되면 강제로 `hideAsync()` (스플래시에 갇히지 않게) |
| 5 | 인트로가 아닌 화면으로 시작(딥링크·알림 진입 등) | 해당 화면 루트 마운트 시 `hideAsync()`. 인트로 시퀀스 없음 |
| 6 | 동작 줄이기 켜짐 | 닫는 시점 동일, 이후 opacity 200ms만 |

- 스플래시 설정 변경은 **네이티브 빌드에 포함**되어 OTA(`expo-updates`)로 반영되지 않는다 → 인트로 모션과 **같은 스토어 빌드**로 낸다(O-16).

## 상태 · 예외

```
[대기: 복원 전] ──복원 완료──▶ [모션 설정 확인 ≤150ms]
      │                              │
      │                ┌─ 첫 실행 ───┴── 재방문 ─┐
      │                ▼                          ▼
      │        [F 재생] ─탭/완료─▶ [F 최종+루프]   [S 재생+루프] ─1.8s/탭─▶ /home
      │                               │ 시작하기
      │                               ▼
      │                           /tutorial (push)
      │                               │ 뒤로가기로 복귀
      │                               ▼
      │                         [최종 상태+루프 재개]
```

- **튜토리얼 완료 직후**: 인트로는 스택 아래에 살아 있다. `tutorialCompleted`가 바뀌어도 포커스가 없으면 S를 시작하지 않는다(기존 주석의 버그와 같은 원인, 같은 방식으로 막는다).
- **빠른 연타**: F에서 탭 → 최종 상태 → 다시 탭해도 아무 일 없음(버튼만 눌러야 이동).
- **에셋 로드 지연**: 레이어 PNG는 `require` 번들 에셋이라 로드 대기 없음. 첫 프레임 깜빡임을 막으려 레이어는 초기 자세(opacity 0)로 렌더해 둔다.
- **저사양 Android**: 모든 값은 transform/opacity만 쓴다(레이아웃 속성 애니메이션 금지). 60fps 유지가 목표, 깨지면 대기 루프부터 끈다.
- **화면 크기**: 그림 영역은 지금 `CatDialogue`의 이미지 슬롯(aspectRatio 1) 안에서만 움직인다. 노렌이 위에서 떨어질 때 슬롯 밖은 `overflow: hidden`으로 자른다.
- **접근성**: 그림 그룹은 `accessible={false}`, 말풍선 문장은 타이핑과 무관하게 **처음부터 전체 문장**을 `accessibilityLabel`로 제공. 재방문의 `"홈으로 이동"` 라벨은 그대로.
- 오류·빈 상태: 해당 없음(네트워크·데이터 의존 없음).

## 에셋 요구 (디자인 → 개발)

모든 레이어는 **같은 정사각 아트보드(1080×1080 @3x, 투명 배경)** 위 제자리에 놓인 채로 내보낸다. 개발은 전부 `absoluteFill`로 겹치기만 하면 된다. 피벗은 아트보드 기준 좌표로 함께 전달한다.

|---|---|---|
| `noren-rod` | 노렌 봉 | — |
| `noren-left` | 왼쪽 폭 | 봉과 만나는 위 중앙 |
| `noren-right` | 오른쪽 폭(「お」 포함) | 봉과 만나는 위 중앙 |
