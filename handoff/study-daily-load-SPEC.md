## 핵심 변경 요약
1. **하루 총량(복습 + 신규) 상한 = max(36, 설정)** — 설정 12면 36, 설정을 37~50으로 올린 사람만 설정값까지. 넘치는 복습은 due가 오래된 것부터 내고, 나머지는 기록을 바꾸지 않고 다음 날로 넘긴다. (이전: 상한 없음 → 7일 쉼 124개, 3일 쉼 74개, 평소에도 최대 68개)
2. **3일 이상 쉬고 돌아오면 학습일 3일 동안 신규 절반(12 → 6개) 보장** — 복습만 하는 날이 없게.
3. **입문자는 FSRS 목표 기억률 0.85** (기본 0.9) — 복습이 조금 늦게 와서 신규가 약 18% 늘어난다.
4. **홈 히어로에 "복습 n · 새 단어 m · 약 k분"** — "하루 새 단어 12"가 총량이 아님을 보이게 한다.
5. "3일 지나면 리셋 / 한 번 본 단어는 다음 단계로"(O-1), 입문자 "복습 반 · 신규 반" 상시 고정(O-5)은 채택하지 않음.

## 조건 → 결과
| 조건 | 결과 |
|---|---|
| 오늘 복습 수 + 신규 ≤ 상한 (`max(36, 설정)`) | 복습 전부 + 신규 `min(설정, 예산 − 복습)`. 예산 = `min(설정×3, 상한)` (작은 설정은 이전처럼 설정×3으로 신규를 줄임) |
| 오늘 복습이 많아 상한을 넘음 (밀림) | 복습은 `상한 − 신규`까지만, due 오래된 것부터. 나머지는 다음 날로 (due·기록 그대로) |
| 3일 이상 연속으로 학습하지 않고 돌아옴 | 돌아온 날 포함 **학습일 3일간** 신규 최소 `ceil(설정/2)`개 보장. 총량은 상한 그대로 (예: 설정 12 → 복습 30 + 신규 6, 설정 50 → 복습 25 + 신규 25) |
| 복귀 3일이 지난 뒤에도 밀림이 남음 | 신규 보장 없이 36 안에서 복습 우선 (보통 1주 안에 0) |
| 처음 만난 신규 30개 중 '다시 볼래요' 15개 이상 (입문자) | 이후 모든 채점(정규 학습·오늘 복습·약점 복습)에 목표 기억률 0.85 |
| 처음 만난 신규가 30개 미만 | 기본 0.9 |
| 설정 37~50 | 상한 = 설정값. 설정 화면 고강도 경고(30 초과)에 "복습 포함 하루 최대 n개까지 나와요" 표시 |
| 설정 변경 | 다음 학습 시작부터 적용 |

|---|---|---|
| 1 | 하루 목록 만들기 (`SessionEngine.start`) | ① 오늘 날짜가 된 복습(선택 레벨)을 due 오래된 순 → ② `planDailyStudy`로 복습 수·신규 수 결정 → ③ 복습을 앞에서 자름 → ④ 신규 채움 → ⑤ 섞기(이전과 같음) |
| 2 | 넘긴 복습 | due를 바꾸지 않는다. 다음 날 ①에서 자연히 앞쪽에 옴 |
| 3 | 복귀 판정 (`isReturnBoostDay`) | review_log의 기기 현지 날짜를 학습일로 본다. 오늘을 학습일로 넣고, 가장 최근 "연속 3일 이상 학습 없음" 뒤의 학습일이 3일 이하면 보장 기간. 처음 학습하는 사용자는 해당 없음. 같은 날 두 번째 세션도 같은 판정 |
| 4 | 입문자 판정 (`isBeginner`) | review_log에서 `state_before = new`이고 FSRS를 갱신한 기록을 시간순으로, 단어별 첫 기록 30개만 본다. 처음 30개로만 정하므로 한 번 정해지면 바뀌지 않음 |
| 5 | 목표 기억률 적용 | 학습·오늘 복습·약점 복습 엔진을 만들 때 `schedulerParams(requestRetentionFor(logs))` |

| 7 | 2차 기억 확인 | 변경 없음 (FSRS 기록 안 함) |

## 상태 · 예외
- 상태: `평상` ↔ `밀림`(복습 + 신규 > 36) / 별도로 `복귀 보장`(학습일 3일). 두 상태는 겹칠 수 있다. 상태는 저장하지 않고 review_log에서 매번 계산 — 백업·복원 시 함께 따라온다.
- 엣지케이스:
  - 30일 이상 쉼: 밀림이 수백 개라도 하루 36. 복귀 3일 뒤에는 신규 0으로 복습만 하다가 밀림이 줄면 신규가 다시 나온다.
  - 학습 중간 종료: 남은 카드는 이전처럼 다음 날 다시 due.
  - 신규 단어 소진(단어장 끝): 신규 0, 36 안에서 복습만.
  - 기기 시간대 변경: 현지 자정 기준으로 판정하므로 하루가 겹치거나 빌 수 있음 — 영향은 복귀 판정 하루 정도.
- 빈: 복습 0 · 신규 0이면 이전처럼 오늘 복습(약점)으로 보낸다. 오류·로딩: 해당 없음(로컬 계산).
