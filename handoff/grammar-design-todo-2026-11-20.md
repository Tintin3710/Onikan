# 문법 학습 — 디자인 할 일 (2026-11-20)

> 기준: 앱 저장소 `docs/02-design/features/ashitakanji.grammar.design.md` (브랜치 `docs/grammar-design`, PR taiyoungkim/AshitaKanji-app#22, 커밋 50cf9f0)
> 기획서 상태: 초안 · 미구현. "확정"과 "제안"이 섞여 있어, 제안 항목은 바뀔 수 있다.

## 0. 기획 요약 (디자인에 영향 있는 것만)

- 단어 학습과 **분리된 "오늘의 문법" 세션**. 단어는 "뒤집고 스스로 평가", 문법은 "문제 풀고 자동 채점".
- 범위는 **N5 문형 64개 먼저**. 하루 새 문형 기본 2개(설정 0~5, 0 = 문법 끔) → 32일이면 끝남.
- 입력은 **고르기·타일만** (키보드 없음). 하트·벌칙 없음.
- 문형 1개 = 복습 카드 1장. 한 번의 복습 = 문제 1개. 틀리면 다음 날 같은 문장이 다시 나옴.
- 예문·문제는 AI가 만들고 검수 → 화면에 **AI 고지 문구**와 **오류 제보 버튼**이 필요.
- 예문 음성은 기기 TTS로 시작.
- 문법 세션만 해도 그날 재료 지급(제안).

## 1. 지금 앱에 없는 것 (새로 만들어야 함)

| 필요 | 지금 앱 | 비고 |
|---|---|---|
| 4지선다 보기 버튼 | 없음 (단어는 "모름/안다" 자가평가만) | 기본 · 선택 · 정답 · 오답 · 비활성 상태 |
| 어순 타일(조각) | 없음 | 조각 은행 · 빈 슬롯 · 놓인 조각 · 오답 조각 |
| 후리가나(한자 위 읽기) 텍스트 | 없음 (기획서 §7에도 "컴포넌트 없음") | 예문·문제 문장 공통. 크기·간격·다크 모드 |
| 접속 구조식 표시 | 없음 | 예: `명사 + に + 명사 + が + あります` |
| 말투 배지 | 없음 | 정중 / 보통 / 글말 |
| 채점 결과 피드백 | 단어엔 없음 | 정답 / 오답 + 고른 오답의 한 줄 설명 |

## 2. 1단계 — 문형 목록·상세 (읽기 전용, 단독 출시 가능)

| 화면 | 들어갈 것 | 상태·예외 |
|---|---|---|
| **진입점** | 홈 카드 vs 탭 — ⚠️ 미정(§10). 지금 탭은 홈·도감·통계·설정 4개 | 문법 끔(하루 0개)일 때 노출 여부 |
| **N5 문형 목록** | 64개 순서대로, 문형 · 한국어 뜻 | 검수 끝난 문형만 보임 → 64개보다 적을 수 있음. 2단계부터는 문형별 학습 상태(안 배움 / 배움 / 약점) 표시 |
| **문형 상세** | 진도 위치 "N5 3/64" · 문형 · 한국어 대응 문형 · 접속 구조식 · 말투 배지 · 설명 · 주의 상자(자주 하는 실수) · 비슷한/반대 문형 비교 한 줄씩(눌러서 이동) · 예문 2개(후리가나 + 번역 + 듣기) · 오류 제보 · AI 고지 | 주의·비교가 없는 문형, 예문 긴 문장 줄바꿈 |
| **N4 이상 사용자** | ⚠️ 미정: 숨김 / N5 권유 | N5만 있는 동안 |

## 3. 2단계 — 문법 세션 (N5 출시)

기획서가 직접 꼽은 2단계 화면은 **문형 카드 · 빈칸 고르기 · 어순 퍼즐 · 결과·설명** 넷이다. 그 밖에 홈·설정·통계 변경이 따라온다.

### 3.1 세션 흐름

```
홈 "오늘의 문법" → [새 문형] T1 문형 카드 → T2 빈칸 고르기 1문제 → 결과
                 → [복습]   T2 또는 T8 1문제 → 결과
                 → (틀린 문제) 세션 끝에 같은 문장을 어순 퍼즐로 다시(채점 안 함)
                 → 세션 완료 (+ 재료)
```

### 3.2 화면별

| 화면 | 들어갈 것 | 상태 |
|---|---|---|
| **T1 문형 카드(소개)** | 문형 상세의 요약판 + 버튼 2개: "알겠어요"(→ 바로 문제), "이미 알아요"(→ 건너뜀) | "이미 알아요" 확인 단계 여부 ⚠️ 미정 |
| **T2 빈칸 고르기** | 장면 한 줄(예: 병원에서) · 필요하면 A/B 두 줄 대화 · 빈칸 문장 · 빈칸 옆 형태 표시(예: 〔정중·과거〕) · 보기 4개 | 장면 없음 / 대화형 / 형태 표시 있음·없음 조합. 긴 보기 줄바꿈 |
| **T8 어순 퍼즐** | 고정 앞부분 + 빈 슬롯 + 고정 뒷부분 · 조각 은행(오답 조각 1~2개 섞임) | 오답 조각 없는 판(T5 재출제와 공용) · 맞는 조각인데 순서만 틀림 → "한 번 다시 놓기" 상태 · 오답 조각을 넣음 → 틀림 |
| **결과·설명** | 정답: 짧은 칭찬 + 완성 문장(후리가나·번역·듣기). 오답: 정답 표시 + **고른 오답의 한 줄 설명** + 문형 카드 요약 + 오류 제보 | 바텀시트 vs 화면 하단 고정 패널 결정 |
| **다시 풀기(T5)** | 세션 끝, 틀린 문장을 어순 퍼즐로 | "채점 안 함"을 알려 줄지 표시 결정 |
| **세션 완료** | 푼 문형 수 · 새로 배운 문형 · 틀린 문형 · 재료 보상 | 재료 지급 여부(⚠️ 미정)에 따라 문구 갈림 |

### 3.3 기존 화면 변경

| 화면 | 변경 |
|---|---|
| **홈** | "오늘의 문법" 진입 + 상태: 문법 할 것 있음 / 문법 완료 / 문법 끔. **단어 완료와 문법 완료를 따로** 보여야 함(기획서 §6.3: 문법만 끝내도 "오늘 학습 완료"로 바뀌면 안 됨). 단어·문법 조합 4가지 상태 시안 필요 |
| **학습 설정** | "하루 새 문형" 0~5 (0 = 문법 끔) |
| **통계** | 문법 수 따로 표시(단어 수와 섞지 않음) |
| **백업** | 문법 기록 포함 — 화면 변경은 문구 정도 |

## 4. 3단계 이후 (지금 시안 불필요, 컴포넌트 설계 때 고려)

| 형식 | 화면 요점 |
|---|---|
| T6 패턴 보고 완성 | 같은 문형 문장 2개 + 셋째 문장 빈칸 |
| T7 두 문장 대비 | 대비 문장 둘을 나란히, 같은 보기 묶음으로 빈칸 하나씩 |
| T3 정오 판정 | 맞다/틀리다 → 틀리다면 틀린 곳 누르기 |
| T4 해석 고르기 · T10 짝 맞추기 · T14 ★ 자리 고르기 · T9 활용형 고르기 | 연습(채점 안 함) |
| 약점 복습에 문법 통합 · 문법 북마크 · 문항별 정답률 | |
| 4단계: T11 군더더기 찾기 · T12 대화 완성 · T13 문장 조립 · T15 글 속 문법 | |

→ 2단계에서 보기 버튼·타일·후리가나·결과 패널을 **3단계 형식까지 쓸 수 있게** 설계해 두면 다시 만들 일이 줄어든다.

## 5. 디자이너가 정해야 할 것 (기획서 §10 중 디자인 몫)

1. **진입 위치**: 홈 카드 / 탭 추가 / 홈 안 섹션.
2. **형태 표시 표기**: 한국어(〔정중·과거〕) / 문법 용어 / 처음엔 숨기고 힌트로 열기.
3. **"이미 알아요"**: 바로 넘기기 / 확인 문제 1개 거치기.
4. **연습 형식 위치**(3단계): 세션 앞 몸풀기 / 세션 뒤 추가 연습 / 별도 메뉴.
5. **문법만 해도 재료**: 유지하면 홈·완료 화면 문구가 갈린다.
6. **N4 이상 사용자**: 숨김 / N5 권유.
7. **예문 속 단어 누르기 → 단어 상세**: 자료가 없어 지금은 불가. 시안에 넣을지.
8. **AI 고지 문구 위치**: 문형 상세 하단 / 목록 상단 / 첫 진입 1회.

기획서에 없지만 디자인 쪽에서 정할 것:
- **세계관 연결**: 단어는 주먹밥·재료·고양이 사장님 세계관인데, 문법은 아직 은유가 없다(메뉴? 레시피? 별도 없음?).
- **말투**: 앱 안내는 사장님 반말("○개 외웠어"), 문법 설명·오답 설명은 기획서 문체 그대로면 존댓말/평서 — 어느 쪽으로 맞출지.
- **오류 제보 방식**: 버튼을 누른 뒤 무엇이 열리는지(메일 / 폼 / 선택지).

## 6. 추천 순서

1. 진입 위치 · 세계관 · 말투 결정 (나머지 시안의 전제)
2. 새 컴포넌트: 보기 버튼, 어순 타일, 후리가나 텍스트, 결과 패널 (라이트·다크)
3. 1단계: 문형 목록 · 문형 상세
4. 2단계: T1 · T2 · T8 · 결과 · 세션 완료
5. 홈 상태 조합 · 학습 설정 · 통계
