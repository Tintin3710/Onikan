## 핵심 변경 요약
1. 수익 구조를 **광고 + 광고 제거 단품** → **광고 + 구독형 패스(광고 제거 포함 + 기능)** 로 넓힌다. 기존 광고 제거 구매자 권한은 그대로 둔다.
2. **핵심 학습 고리(매일 학습 · 복습 · 메뉴 24종 · 기본 기록)는 무료 유지.** 유료는 깊이(시험 대비) · 편의(휴무권 · 위젯) · 소장(월간 영수증 · 시즌 메뉴)에 둔다.
3. 1차 출시 기능: **가게 휴무권 · 월간 영수증 리포트 · JLPT 목표일 플랜**(개발 비용 대비 가치가 큰 순).
4. 기록 탭에 **무료 이벤트 코너**(오미쿠지 수집 · 사장님 편지 · 이달의 노래 · 이달의 문장)를 만들어 유지율과 "매일 열어볼 이유"를 늘린다. 마이모리 설정 화면의 섹션형 카드 구성을 차용.
5. 앱은 **서버 없는 로컬 전용**이다. 구독 확인은 스토어(`expo-iap`)만으로 하고, 월간 콘텐츠는 처음엔 앱에 넣어 날짜로 연다(O-12).

## 2. 원칙

1. **습관을 막지 않는다.** 매일 학습·복습·보상(재료·메뉴·도장)은 무료에서 끝까지 된다. 결제벽 때문에 학습이 끊기면 광고 수익도 같이 사라진다.
2. **"더 깊게 · 더 편하게 · 더 갖고 싶게"만 유료.** 무료 기능을 줄여서 유료로 옮기지 않는다(기존 사용자 신뢰).
3. **대상은 30~40대 직장인.** 결제 이유는 "합격 · 시간 절약 · 바쁜 날 보호". 아이 같은 보상 남발 대신 실용 가치를 앞에 둔다.
4. **브랜드 규칙 유지.** 결제 CTA도 잉크 버튼 1개(`button-primary`), 오렌지는 버튼에 쓰지 않음, 라임은 획득 순간에만. 사장님 반말 톤.

### F-1 가게 휴무권 상세
- 사장님 말투: "오늘은 가게 쉬는 날로 해 둘게."
- 동작: 어제 학습이 없고 휴무권이 남아 있으면, 오늘 앱을 열 때 **어제를 휴무일로 자동 처리**(O-7). 단골 일수는 **유지되지만 늘지 않는다**(듀오링고 스트릭 프리즈와 같은 방식).
- 구현: `computeStreak`에 휴무일 집합을 넘겨 "그날은 끊긴 날로 보지 않되 count는 올리지 않음". 휴무일 목록은 로컬에 영속.
- 고양이 카드 영향: 단골 최대값이 유지되므로 카드 해금이 끊기지 않음 → 패스 혜택으로 자연스럽다. 휴무일로 카드가 **추가 해금되지는 않는다**(count 미증가).
- 표시: 기록 탭 달력·단골 도장 그리드에 휴무일은 별도 표시(도장 대신 "휴" 마크, `mute` 계열). ⚠️ 시안 필요(O-8).

### F-2 월간 영수증 리포트 상세
- 매달 1일 기록 탭 "이달의 코너"에 지난 달 영수증 도착.
- 항목 예: 방문일 수 · 익힌 단어 · 복습 수 · 완성 메뉴 · 가장 많이 틀린 단어 3개 · 사장님 한 줄.
- 디자인: `receipt` 컴포넌트(`radius/receipt`, `receipt/title`·`receipt/footer` 자간 3px) 그대로. 공유는 이미지 저장 + OS 공유 시트.
- 데이터: 기존 `RecordService` 세션 기록으로 계산 가능. 서버 불필요.

### F-3 JLPT 목표일 플랜 상세
- 입력: 시험일(7월·12월 회차 선택 또는 직접), 목표 레벨(N5~N1 중 지금 선택된 레벨).
- 계산: (목표 레벨 남은 단어 수 + 복습 여유) ÷ 남은 일수 → 권장 하루 신규 단어. **설정의 하루 신규 단어 값은 사용자가 수락할 때만 바꾼다.** 상한 50을 넘으면 "이대로면 빠듯해" 안내.
- 표시: 홈 상단 D-day 칩, 기록 탭 진도 예측 그래프("이 속도면 ○월 ○일에 N4 단어 완료").
- ⚠️ 시험 일정 하드코딩 vs 사용자 입력(O-9).

## 5. 무료 이벤트 코너 (기록 탭)

마이모리처럼 섹션형 카드로 구성한다. **모두 무료** — 유지율이 패스 전환의 바탕이다.

| 섹션 | 카드 | 내용 | 주기 |
|---|---|---|---|
| 나의 가게 | 단골 · 익힌 단어 · 완성 메뉴 · 복습 수 | 지금 있는 통계 숫자 카드 | 실시간 |
| 이달의 코너 | **사장님 편지** | 사장님이 쓰는 짧은 반말 편지 + 지난 달 기록 한 줄 | 매달 1일 |
| | **이달의 노래** | JPOP 한 곡 추천 + 곡에 나오는 표현 1~2개 해설 + 음원 앱 링크 | 매달 |
| | **이달의 문장** | 일본어 문장 1개 + 읽기 · 뜻 · 쓰는 상황 | 매달 |
| | 월간 영수증 | F-2. 무료는 숫자 요약, 패스는 영수증 전체 | 매달 1일 |
| 컬렉션 | **오미쿠지 n/365** | 학습 완료 후 하루 한 장 뽑기. 大吉·中吉·小吉 등 + 사장님 한마디 + 일본어 표현. 칸 그리드 수집판, 탭하면 쪽지 모달 | 매일 |
| | 고양이 카드 | 기존 | – |

- **이달의 노래 저작권:** 가사는 앱에 싣지 않는다. 곡 제목·가수 + 짧은 표현 해설(직접 쓴 예문)만, 감상은 외부 링크.
- **오미쿠지**는 마이모리 "도토리(n/200 그리드 + 메시지 모달)"의 오니칸 버전. 학습 완료라는 기존 보상 고리에 붙어서 "오늘도 열어볼 이유"를 만든다. 운세는 전부 긍정·중립 톤(凶 없음 권장, O-11).

## 상태 · 예외

- **권한 상태:** `무료` → (구매) → `패스 활성` → (해지 예약) `활성·갱신 안 함` → (기간 끝) `만료` → `무료`. 광고 제거 단품은 이 흐름과 별개 플래그(`adFree`)로 유지.
- **광고 노출 판단:** `adFree = 단품 보유 || 패스 활성`. `adPolicy.isEligible` 앞에서 한 번만 검사.
- **엣지케이스:** 두 기기 사용(같은 스토어 계정이면 복원으로 동기화, 학습 기록은 백업 기능 범위) · 가족 공유(iOS, O-14) · 체험 중 해지(체험 끝까지 사용) · 결제 실패 유예 기간(스토어가 활성으로 돌려주는 동안은 활성).
- **빈 / 오류 / 로딩:** 상품 정보 로딩 중엔 가격 자리 스켈레톤, 스토어 연결 실패 시 "지금은 결제를 할 수 없어요. 잠시 뒤 다시 시도해 주세요." + 다시 시도. 이벤트 코너는 콘텐츠가 없는 달이면 카드 숨김(빈 카드 노출 안 함).
- **테스트:** 스토어 샌드박스·테스트 트랙 계정으로만 검증한다. 실제 결제·운영 계정 로그인은 하지 않는다.
