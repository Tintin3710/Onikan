## 6. 순환 동작 (A, 2026-11-11 구현 — fork, 커밋 전)

| 조건 | 결과 |
|---|---|
| 재료 96개(24종)를 다 모음 | 다음 세션부터 **1번 메뉴부터 다시** 재료를 모은다. 재료 지급은 멈추지 않는다 |
| 다시 만드는 메뉴의 상태 | 이미 만든 메뉴라 `완성` 유지(메뉴판에서 잠기지 않음). 진행 재료 수는 이번 바퀴 기준 |
| 다시 완성 | 완성 화면 뱃지 `n번째 완성` (처음은 `완성`) |
| 메뉴판 목록 | 2번 이상 만든 메뉴는 `완성 ×n` |
| 메뉴판 상단 카드 | 처음: `만드는 중` / 다시: `다시 만드는 중 · n번째` — 다 모은 뒤에도 카드가 계속 보인다 |
| 메뉴판 하단 문구 | `전부 모았네. 이제 1번부터 다시 만들어 볼까.` |
| 결과 화면 `수집 완료` 문구 | 보상이 있는 세션에는 쓰지 않는다(순환 중엔 항상 새 재료 문구) |
