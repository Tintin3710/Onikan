## 완성한 날 흐름 — 08 A안 확정 (2026-11-12)
01(참치마요 3/4) → 05(마요네즈로 4/4) → 06 완성 화면 → 영수증 → 08 학습 후 홈. 앱 포크 `f16d088`에 반영, 시뮬레이터에서 확인.

| # | 상황 | 동작 |
|---|---|---|
| 1 | 05에서 확인 (마지막 재료) | 06 '새 주먹밥을 만들었어요.' 화면 (완성 뱃지, 학습 단어·학습 시간·단골 기록, 사장님 한마디) |
| 2 | 06에서 '영수증 받고 마치기' | 영수증 → 홈 |
| 3 | 08 학습 후 홈, 오늘 완성함 | 아래 줄이 '오늘 완성한 메뉴 [완성] / 참치마요 오니기리 / 마지막 재료 마요네즈'. 누르면 레시피 상세 |
| 4 | 08 학습 후 홈, 완성 안 함 | 기존대로 '오늘 획득한 재료 / 참치마요 재료 n/4' |
| 5 | 완성한 날의 '최근 획득' 카드 | 숨김 (위 카드와 겹침) |
| 6 | 두 번째 바퀴 이후 완성 | 뱃지 'n번째 완성' |

그림에서 고칠 곳:
- 08 그림(밥 1/4, 단어 20개)은 옛 안이다. A안 줄로 다시 그려야 한다.
- 06 그림의 학습 단어 20 → 22 (05와 같은 학습). 날짜 '목요일' → '금요일'.
- 흐름 그림에서 06 다음 바로 홈으로 가는데, 앱은 사이에 영수증이 있다.

참고: 단골 문구 '다음 학습 재료 2배'는 문구만 있고, 실제로는 학습 1번에 재료 1개만 준다.

## 기준 이미지로 쓸 때 주의
- 그림 데이터가 fixture와 달라 그대로 비교하면 글자·숫자 부분이 전부 차이로 잡힌다. 쓰려면 fixture를 그림에 맞추거나, 그림을 fixture에 맞춰 다시 내보내야 한다.
- 01·08은 홈 긴 화면이라 비교 도구가 위 756px + 아래 탭바 88px만 잘라 쓴다.
- `ui/manifest.json`의 designRoot가 다른 컴퓨터 경로(`/Users/tyoung/...`)라 이 컴퓨터에서 `ui:approve --from-design`은 그대로 돌지 않는다.
