## 핵심 요약
앱을 **처음 연 유저**가 학습→재료 획득→영수증까지 **한 사이클을 미리 체험**하는 온보딩. **3단어(O-8)** 짧은 세션이며, **"연습"이라 결과·스트릭·재료는 저장되지 않고**(O-6) 마지막에 실제 오늘 학습으로 진입한다.

- 흐름: **① 시작(사장 인사) → ② 안내(먼저 3개만) → ③④ 학습(앞면→뜻 공개, 평가) → ⑤ 재료 획득(파티클+자동 넘어감) → ⑥ 영수증(출력 모션·연습) → ⑦ 마침(오늘 학습 시작)**
- **히라가나 선택(2026-11, O-14~O-16)**: 학습 카드 아래 `히라가나부터 배울래요` → 확인 시트 → 한글 발음 표시 + 후리가나 변경 안내 1회 → 마침에서 `히라가나 배우기`. **누른 사람에게만** 제공, 기본 흐름은 그대로.
- 재사용: `PhoneticHintCard` · `ExampleTTSCard` · `GradeButtons` · `buttonAutoFill(M-1)` · `confettiBurst(M-2)`.
- 신규: 온보딩 일러스트 화면 3종(N-8) · **영수증 출력 모션(M-3)**.

## 가나 표 (O-17·O-19, 2026-11-11)
> 벤치마킹: 일본어 알파벳 표 앱(히라/가타 전환 · 오십음/탁음/요음 탭 · 행·단 재생). 가져온 것 = 표 + 탭 넘기기 + 재생 중 칸 테두리. 고친 것 = 아래 O-19.

## 상태 · 예외
- **학습 카드 2상태**: 앞면(뜻 가림, `뜻 보기`) ↔ 뒷면(뜻 공개, `아직이에요` outline·`외웠어요` 잉크). = `GradeButtons` 학습 variant.
  - ⚠️ 확인 필요 — 정규 학습 버튼이 개선안(`다시 볼래요`/`한 번 익혔어요`, UT 2026-11 비교 중)으로 확정되면 온보딩도 같은 이름으로 맞춘다. 첫 탭 피드백(`../../study-first-tap-feedback-SPEC.md`)을 온보딩 3단어에도 적용할지 함께 결정.
- **진행바**: 상단 연속 1자 바 + **`N / 3`**(O-8). *(초기안 5단어 → 10단어(Figma 298-44943) → **2026-11 3단어**, 앱 구현 기준으로 정합.)*
- **한글 발음 pill**: 후리가나 오른쪽, `plate` 배경·잉크 글자(뉴트럴). 오렌지·라임 사용 안 함. 뜻 공개 전에도 표시(후리가나와 같은 규칙 — `뜻 보기 전 후리가나` 끄면 함께 가림).
- **히라가나 선택 상태**: `kanaMode`(저장) · `kanaHintSeen`(저장). 온보딩을 처음부터 다시 해도 선택은 유지되고 링크는 숨김.
- **② 안내(O-13)**: "?" 미스터리 주먹밥 + "어떤 주먹밥이 완성될까?" **제거**(디자인 수정). `계속` = buttonAutoFill 자동 진행.
- **완성 분기**: 재료 4/4 완성 시에만 오니기리 완성 화면. 온보딩은 미완성 → 건너뜀.
- **영수증(온보딩=연습 1종, O-10)**: 참치마요 주먹밥 카드 + `ありがとう · 연습` + 단일 CTA `확인했어`(화이트). 실제 결과의 `이미지로 저장`·`공유`·`홈으로`·진행바는 **온보딩 미노출**(실제 학습 전용, `screens/06b` 참고).
- **CTA 색(O-9)**: 주요 액션 = **잉크**(D-3). **라이트 화면**(시작·안내·학습·마침) = 잉크 다크 버튼. **다크 서피스**(영수증) = **화이트 버튼 + 잉크 텍스트**(인버트).
- **접근성**: `reduced-motion` 시 파티클·자동 fill·출력 모션 비활성.
- **빈/오류/로딩**: TTS 실패 시 🔊 비활성(무음). 온보딩 콘텐츠는 로컬 고정(네트워크 무관).

### 한글 발음 표기 규칙 (O-16)
> 원칙: 한국어 외래어 표기법이 아니라 **실제 일본어 발음을 배우게** 하는 표기. 단어별로 검수한 값을 쓰고, 가나에서 기계 변환하지 않는다(`おう`가 장음인지 두 음절인지는 단어마다 다름).

| 현상 | 규칙 | 예 |
|---|---|---|
| 장음 (おう·えい·ああ·ー 등 실제로 길게 읽는 경우) | **`ー`로 표기** (가타카나 장음 기호와 같은 모양 — 일본어 장음 개념을 그대로 학습) | べんきょう → 벤쿄ー · せんせい → 센세ー · コーヒー → 코ー히ー |
| 장음이 아닌 모음 연속 | 그대로 두 글자 | おもう(思う) → 오모우 · いう(言う) → 이우 |
| 촉음 っ | 앞 글자 받침 `ㅅ` | がっこう → 갓코ー · きって → 킷테 |
| 청음 / 탁음 구별 | 청음 = 거센소리, 탁음 = 예사소리 (어두·어중 동일) | か 카 / が 가 · た 타 / だ 다 |
| つ · ず · す | 츠 · 즈 · 스 | つくえ → 츠쿠에 |
| ん | ⚠️ 확인 필요 — `ㄴ` 고정(벤쿄ー) vs 뒤 소리에 따라 ㅁ·ㄴ·ㅇ(벵쿄ー). 제안: 학습 초기 혼동을 줄이려 **ㄴ 고정 + 음성으로 보완** | |
