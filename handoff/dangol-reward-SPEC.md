## 핵심 변경 요약
1. **단골 도장 10칸을 다 채우면 보상 = "고양이 카드" 1장** 을 지급한다. (기존엔 10-완성 보상이 미정이었음)
2. 카드 = **실제 고양이 사진 기반 포켓몬 패러디 수집 카드**(도감번호·HP·기술·플레이버). 톤은 **사장 반말 병맛**.
3. 도장 카드 하단 라벨 **`단골 혜택 · 다음 학습 재료 2배` 는 폐기** → 보상을 살짝 흘리는 **티저형 사장 대사**로 교체(문구 후보는 O-3).
4. 색/컴포넌트 규칙은 정본 유지 — 단골 도장은 **오렌지**(브랜드·상태, D-3), 카드 UI는 신규(N-1).

## 상태 · 예외
- **상태 전이(사이클):** `적립 진행(0–9)` → `완성(10)` → `카드 지급` → `(리셋?)` 새 사이클. 리셋 규칙 미정(O-5).
- **빈 상태:** 도장 0칸 — 그리드 전부 locked, 티저 라벨만 노출.
- **완성 미수령:** 앱을 껐다 켜도 미수령 카드는 보존되어 재진입 시 수령 가능해야 함 — ⚠️(O-6: 미수령 보관/재수령).
- **중복 카드:** 동일 카드 재획득 시 대체 보상 여부 미정(O-8).
- **오프라인/시간 조작:** 단골 적립 트리거가 "학습 완료" 기반이면 날짜 조작 영향 적음 — 트리거 확정 필요(O-4).
- **접근성/색:** 단골 도장은 오렌지 고정(D-3). earned/locked는 색만이 아니라 채움 형태로도 구분(이미 stamp-earned/locked 에셋 분리).

## 카드 포맷 (패러디 · 예시 "광주리 고양이" 기준)
> 포켓몬 카드 레이아웃 오마주. 실제 고양이 사진 + 병맛 카피. UI 신규 컴포넌트(N-1) — 정식 컴포넌트화 시 `../COMPONENTS.md`에 계약 추가.

| 영역 | 내용 | 예시 |
|---|---|---|
| 유형 배지 | 진화/유형 라벨 | `기본` |
| 이름 · HP · 타입 | 카드명 / 체력 / 타입 심볼 | `광주리 고양이` · `HP 70` · `⭐` |
| 사진 + 말풍선 | 실제 고양이 짤 + 사장 대사 | "여기 내 자리야." |
| 도감줄 | 번호 · 이름 · 키 · 몸무게 | `No.025 · 키 약 30cm · 몸무게 약 4.5kg` |
| 기술 1–2 | 코스트 심볼 · 기술명 · 데미지 · 병맛 설명 | `편안한 자리 10` / `째려보기 30` |
| 하단 스탯 | 약점 · 저항력 · 후퇴 | `약점 🐾×2 · 저항력 – · 후퇴 🐾🐾` |
| 플레이버 | 맨 아래 한 줄 | "광주리에 담긴 고양이. 처다보면 싫어한다." |
| 번호/등급 | 도감번호 · 레어도 | `025/100 C` |

- ⚠️ 총 도감 수·레어도 운용은 O-10에서 확정. 예시의 `100`, `C`는 placeholder.
- 저작권: 실제 고양이 사진은 **권리 확보된(직접 촬영/라이선스) 이미지만** 사용. 포켓몬 상표·로고·폰트는 **직접 모방 금지**(레이아웃 오마주 수준까지만).
