# 오니칸 인터랙션 스펙 — 재료 노출 · 기록

학습 완료 시 **재료 노출(reward release)** 과 **기록 페이지**의 구성·모션 명세.
프로토타입: [`onikan-interactions.html`](./onikan-interactions.html) — 상단 툴바에서 화면 전환 / 테마 전환(☀︎·☾) / 다시 재생(↻).

> 모든 색·타이포·라운드·스페이싱은 [`../../DESIGN.md`](../../DESIGN.md) 토큰을 그대로 따른다.
> 원칙: **오렌지 = 화면당 단 하나의 주요 행동**, **라임 = 보상 획득의 순간에만**, 나머지는 뉴트럴.
> 이 두 화면은 어느 학습앱의 "완료 축하 + 통계 시트"의 **리듬만 참고**하고, 표현은 오니칸의 절제로 재해석했다
> (콘페티 → 라임 1회 펄스, teal/sage 액센트 → 잉크·그레이).

## 공통 모션 원칙

| 항목 | 값 |
|---|---|
| 등장(fade+rise) 이징 | `ease-out` (`cubic-bezier(0,0,.2,1)` 계열) |
| 팝/펄스(오버슈트) 이징 | `cubic-bezier(.34,1.56,.64,1)` — spring 유사, 살짝 오버슈트 |
| CTA 슬라이드업 이징 | `cubic-bezier(.22,1,.36,1)` |
| 그룹 스태거 간격 | 60–120ms |
| 숫자 카운트업 | 550ms, `easeOutCubic`(`1-(1-p)³`), **tabular-nums** |
| 라임 사용 시간 | "켜졌다 잉크로 가라앉는" 짧은 순간만 (펄스 1회, 스파크 ≤250ms) |
| 접근성 | `prefers-reduced-motion: reduce` → 모든 애니메이션 생략, **최종 상태만 페이드** / 카운트업·드로잉 미실행 |

## 화면 A — 학습 완료 / 재료 노출

기존 완료 화면(`../screens/7a-result-light.png`)을 계승. 진입 시 자동 재생, 총 **~1.8s**.

**레이아웃(위→아래):** 섹션 라벨 `오늘의 학습` → 헤드라인 `다 했어요`(display-xl) → **재료 카드**(재료 아트 + 라임 체크 뱃지 / `새 재료`·재료명·설명) → 레시피 진행(`참치마요` `1/4` + progress-dots + 안내) → 통계 2행(`새로 배운 단어 12` / `아직이라고 표시한 단어 3`) → 안내문 → 하단 풀폭 오렌지 CTA `영수증 받고 마치기`.

### 타임라인

| 시작 | 요소 | 동작 |
|---|---|---|
| 0.05s | 재료 아트 | `scale .8 → 1` + fade, 오버슈트 팝인 (0.42s) |
| 0.34s | 라임 체크 뱃지 | `scale .3 → 1.15 → 1` 팝 + 체크 stroke draw(0.3s) |
| 0.42s | 라임 링 펄스 | 링 `scale .7 → 2.1`, opacity `.55 → 0` — **1회만** (0.7s) |
| 0.42s | 라임 스파크 ×5 | 방사형으로 짧게 튀며 소멸 (0.5s, ≤250ms 내 사라짐) — 콘페티 아님, 절제 |
| 0.55s | 레시피 블록 | fade + `translateY 10→0` (0.5s) |
| 0.70s | 획득한 진행 칸 | 테두리만 있던 칸이 **라임으로 채워졌다가 잉크로 정착** (`outline → lime → ink`, 0.6s). `0/4 → 1/4` 카운터 틱 |
| 0.70s | `새로 배운 단어` | `0 → 12` 카운트업 (0.55s) |
| 1.15s | 안내문 | fade in |
| 1.25s | 오렌지 CTA | 아래에서 `translateY 24→0` + fade 슬라이드업 (0.45s) |

**라임이 등장하는 지점(=보상):** ① 체크 뱃지 ② 링 펄스 ③ 스파크 ④ 방금 채워진 진행 칸. 그 외에는 라임 없음.

## 화면 B — 기록

하단 탭 `기록` 또는 바텀시트로 진입. 진입 시 슬라이드업, 콘텐츠 스태거 등장.

**레이아웃(카드 사이 28px):** ✕ 닫기 + 라지 타이틀 `기록` → **테스트 점수 카드**(`16/30` · 날짜 · chevron) → **연속 학습 카드**(불꽃+연속일 / 우상단 공유·더보기 / 요일 체크 로우) → **스탯 타일 2×2**(`128 읽은 단어`·`4 즐겨찾기`·`7 저장`·`10 학습`, 카드당 히어로 숫자 1개) → **분포 카드**(`전체 학습자의 4%를 앞섰어요`·`내 점수 29` / 정규분포 곡선 + `나` 마커 + `평균` 점선 + 축 `0·평균·100` / 오렌지 CTA `지금 연습하기`).

### 인터랙션

- **라지 타이틀 축소(스크럽):** 스크롤 오프셋 `t = clamp(scrollTop/48, 0, 1)`.
  - 큰 `기록` 타이틀 `opacity 1→0`, `translateY 0→-8px`, `scale 1→.88`
  - 상단 중앙 인라인 타이틀 `opacity 0→1`
  - 헤더 배경 blur + 하단 헤어라인 `scrollTop > 6`에서 등장
- **콘텐츠 등장 스태거:** 각 카드 `fade + translateY 12→0`, 딜레이 `0.05s → 0.42s` 순차.
- **스탯 카운트업:** `16` · `128` · `4` · `7` · `10` · `4`(상위) 모두 `0 → 목표` (550ms, tabular-nums).
- **스트릭 요일 체크:** 유지한 날만 왼→오 순서로 라임 체크 팝인(스태거 60ms), 미달성은 soft 회색 원.
- **분포 곡선 드로잉:** 곡선+면적 fill이 `clip-path: inset(0 100% 0 0) → inset(0 0 0 0)`로 왼→오 드로잉(0.7s, 0.5s 지연). 완료 후 `나` 마커가 제자리에 팝(1.1s).

### `나` 마커 배치 규칙 (중요)

- 마커는 **HTML 정원**(SVG 밖)으로 렌더 → 곡선 SVG를 가로로 늘려도 **찌그러지지 않음**.
- 위치는 **곡선 path 위의 실제 좌표**를 계산해 얹는다: 점수 축(0–100)에서 `내 점수` 위치의 x를 잡고, `getPointAtLength`로 곡선 위 대응점을 찾아 컨테이너 픽셀로 매핑. 리사이즈 시 재계산.
- 곡선 stroke는 `vector-effect="non-scaling-stroke"`로 두께 균일 유지.

## 색 사용 점검 (self-check)

- 화면당 오렌지 CTA는 **하나** (A: `영수증 받고 마치기`, B: `지금 연습하기`).
- 라임은 **보상 순간에만** (A: 체크·펄스·스파크·획득 칸 / B: 스트릭 유지 체크). 분포 곡선·아이콘·차트는 **잉크·그레이**.
- 불꽃은 일러스트 글리프(따뜻한 코랄) — 브랜드 오렌지가 아니며 CTA로 읽히지 않도록 아이콘 스케일로만 사용.
- 카드 안에 카드 없음 / 카드당 히어로 숫자 1개 / 뱃지·라벨 뉴트럴.
