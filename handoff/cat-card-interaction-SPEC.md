## 핵심 변경 요약
1. 도감 스페셜 탭에서 **사진 없는 칸(잠김·사진 준비 전)이 눌린다** → 카드 뒷면 팝업(No.xxx · ??? · 단골 n / N일 진행 막대 · 남은 날 칩 · 사장님 한마디 · ✕). 이전엔 disabled.
2. **사진 카드 → 상세 전환**: 오른쪽 슬라이드(기본 스택) 폐기. **배경·카드·설명 카드가 따로** 움직인다 — 배경은 투명 → 100% 페이드, 카드만 살짝 커졌다 제자리, 설명은 80ms 시간차.
3. **상세 좌우 스와이프** = 이전·다음 카드. 해금 + 사진 있는 카드만 넘긴다.
4. 상세 **아래 여백**: 홈 인디케이터 높이 + 40 (이전엔 인디케이터에 거의 다 가려 실제 여백이 부족).
5. 카드 앞면을 `CatCardFace`로 분리 — **홀로그램 등 카드 이펙트 확장 지점**(overlay 슬롯) 마련.

## 조건 → 결과
| 조건 | 결과 |
|---|---|
| 그리드 칸에 사진 있음(해금 + 데이터 + 사진) | 상세 열림(전환 B) |
| 그리드 칸에 사진 없음 | 잠긴 카드 팝업(전환 A) |
| 팝업: 남은 날 = 1 | 상태 `soon` · 칩 `내일 열려요` |
| 팝업: 지금 연속 < 최고 기록 (남은 날 ≥ 2) | 상태 `broken` |
| 팝업: 그 외 잠김 | 상태 `far` · 칩 `앞으로 n일` |
| 팝업: 카드 데이터·사진 없음(현재 10~24번) | 상태 `noPhoto` · 회색 뒷면 + 카메라 + `사장님 촬영 중` |
| 팝업: 해금됐지만 사진 없음 | `noPhoto` 모양 · 막대 가득 · 칩 `사진 준비 중` |
| 상세 진입 번호가 잠김/없음(딥링크 등) | 페이저 없이 `아직 잠긴 카드예요.` / `카드를 찾지 못했어요.` |

**남은 날 = 카드 번호 − 현재 단골 일수.** 해금은 최고 기록 기준(O-5)이지만 다음 장은 지금 연속이 그 번호에 닿아야 열리므로, 단골이 끊기면 남은 날이 늘어난다. 진행 막대 = 현재 단골 일수 / 카드 번호.

## 모션 수치
코드 정본: `src/features/catCards/catCardMotion.ts` (`CAT_CARD_MOTION`, `CAT_CARD_DETAIL_MOTION`). 이징: 열기 ease-out cubic · 되돌아오기 ease-in-out quad · 닫기 ease-in quad.

### A. 잠긴 카드 팝업
| 요소 | 열기 | 닫기 |
|---|---|---|
| 배경 dim (softer 84%) | 0 → 1, 150ms | → 0, 200ms |
| 카드 뒷면 | 불투명 120ms · scale 0.8 → 1.04 (200ms) → 1 (120ms) · 기울기 −2° 고정 | scale → 0.8 · 투명, 200ms |
| 사장님 말풍선 · ✕ | 80ms 지연 · 아래 8px → 0 · 불투명, 240ms | 투명 · 8px 아래로, 200ms |

### B. 카드 상세 전환 (세 겹 분리)
| 요소 | 열기 | 닫기 |
|---|---|---|
| 배경(카드 테마 page 색) + 상단 바 | 투명 → 100%, 220ms — 도감이 비쳤다가 덮임 | → 0, 200ms |
| 카드 | 불투명 140ms · scale 0.92 → 1.03 (220ms) → 1 (160ms) | scale → 0.92 · 투명, 200ms |
| 설명 카드 | **80ms 지연** · 아래 12px → 0 · 불투명, 260ms | 투명 · 12px 아래로, 200ms |

설명 카드 시간차는 **80ms로 확정** — 동시면 카드와 한 덩어리로 보여 "통째로 커지는" 느낌이 다시 나고, 그 이상 늦추면 기다리는 느낌. 팝업 말풍선과 같은 시간차.

## 상태 · 예외
- 상태 전이(팝업): 닫힘 → 열림(A 열기) → 닫는 중(200ms) → 닫힘. 닫는 중 같은 칸을 다시 누르면 새로 연다.
- 상태 전이(상세): 열림(B 열기) → 닫는 중(200ms, 이 동안 그리드 탭 무시) → 닫힘.
- 페이저 범위: 해금 + 사진 있는 카드만. 첫/마지막 카드에서는 더 넘어가지 않음.
- 빈 상태: 해금 0장이면 그리드 대신 기존 티저 빈 상태(dangol O-3) — 팝업 진입 없음.
- 로딩: 단골 일수 로드 전에는 0으로 계산.

## 개발 메모 — 카드 이펙트(홀로그램)
- `CatCardFace`의 `overlay`: 카드 전체 위 absoluteFill 레이어. 카드 둥근 틀(overflow hidden)에 맞춰 잘리고 터치는 통과(pointerEvents none).
- `photoOverlay`: 사진 영역에만 효과.
- `style`: 카드 틀 자체 transform 자리 — 기울기 반응은 reanimated `useAnimatedSensor`로 Animated 래퍼를 씌운다.
- 그라데이션은 설치된 `react-native-svg`로 가능. 셰이더급 효과는 `@shopify/react-native-skia` 추가가 필요(미설치).
