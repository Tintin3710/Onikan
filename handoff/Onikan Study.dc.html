1. 카드로 감싸되, 무게를 다르게
탭 가능한 영역이 배경 위에 그냥 놓여 있으면 “누를 수 있다”는 신호가 없다 — 지적이 맞다. 다만 3a에서 카드를 피한 이유(두 카드가 같은 무게로 경쟁)도 유효하므로, 그림자로만 층을 나눴다: 히어로는 떠 있는 카드(0 6px 14px), 진행 카드는 그림자도 테두리도 없는 맨 흰 면. 스톤 배경(#F2F2F4) 위에서는 흰 면 자체가 이미 카드로 읽히므로 hairline은 잡음만 더한다 — 뺐다. 같은 흰 면·같은 24px 반경이지만 그림자 유무만으로 한 단 뒤에 놓인다.
2. 셰브론이 진짜 신호
카드보다 더 확실한 탭 힌트는 오른쪽 › 다. 메뉴 리스트·설정 등 앱 전역에서 “들어간다”를 뜻하는 같은 기호로 통일한다. 실제 요소도 <button>이라 press 상태·접근성 라벨을 갖는다.
3. 히어로 카드에서 칩 3개 제거
N5 필 + ‘복습 3’ + ‘약 6분’ 세 개의 알약이 카드 안에서 또 하나의 층을 만들고 있었다 → “N5 · 복습 3개 · 약 6분” 한 줄로 합쳤다. 정보량은 같고, 시각 요소는 3개에서 1개로 준다.
4. 사장 인사 축소
52px 타일 + 2줄 → 44px 타일 + 1줄, ‘— 사장’ 서명 삭제(그림이 이미 화자를 말한다). CTA가 화면 아래에서 더 안정적으로 앉는다.
5. 블록 수 6 → 4
날짜 · 세그먼트 · [히어로 + 진행] · [인사 + CTA]. 12px 간격으로 묶인 카드 두 장이 한 덩어리로 읽혀, 화면이 실제보다 조용해진다.
6. 캡션 단축
“쌀을 받았어요 · 다음 재료는 김” → “재료 1개 모았어요”. 다음 재료 이름은 9a에서 감추기로 했으므로 홈에서도 노출하지 않는다(스포일러 정책 일치).

개선 포인트
1. 영수증을 ‘선택지’가 아니라 ‘결과물’로
2b를 두 번째 버튼으로 되살리면 다시 액션이 둘이 된다. 대신 하나뿐인 CTA의 결과로 만들었다 — “영수증 받고 마치기”를 누르면 영수증이 위에서 인쇄되어 내려온다. 선택 부담 0, 매일 반드시 한 번은 본다.
2. 리추얼의 마침표
가게에서 나오며 영수증을 받는 동작 그대로. 0.9초 프린트 모션이 세션의 끝을 신체적으로 표시해, 앱을 닫는 행동에 감정을 부여한다.
3. 공유는 여기서만
이미지 저장·공유는 영수증이 나온 뒤에만 등장. 결과 화면을 어지럽히지 않으면서, 자연스럽게 확산 자산이 된다(‘24일째’ 연속 기록을 푸터에 넣어 자랑할 거리를 준다).
4. 오렌지는 여전히 하나
영수증이 뜨면 스크림이 화면을 덮고 CTA는 가려진다. 시트 위 버튼은 전부 흰 면/텍스트 — 어떤 순간에도 오렌지는 하나.
5. ‘닫기’ → ‘홈으로’
‘닫기’는 “덮개를 치우면 아까 그 화면”을 암시하는데 실제로는 홈으로 나간다. 세션이 이미 끝난 뒤라 결과 화면으로 되돌아갈 이유도 없다. 버튼이 도착지를 그대로 말하게 바꿨다. 구현 시 결과 화면은 스택에서 제거(replace)해 뒤로가기·스와이프로도 되돌아오지 않게 한다.
5-0. 배경 탭 = 홈으로 (버튼과 동일)
영수증 바깥 어두운 영역을 탭해도 나갈 수 있게 했다. 다만 도착지는 ‘홈으로’와 같다 — 배경 탭은 결과 화면으로, 버튼은 홈으로 보내면 같은 오버레이에 목적지가 다른 출구가 둘이 되어 오히려 예측이 어려워진다. 하나의 오버레이, 하나의 도착지. 영수증 종이와 버튼 영역은 탭이 통과하지 않는다.
5-1. 대안: 영수증을 오버레이가 아니라 화면으로
더 예측 가능한 구조는 영수증을 결과 화면을 대체하는 마지막 화면으로 만드는 것이다(스크림 없이 전체 화면 전환). 오버레이는 “잠깐 떠 있는 것 = 닫으면 원위치”라는 기대를 만들지만, 화면 전환은 “앞으로 나아갔다”를 뜻해 홈으로 나가는 것이 자연스럽다. 다만 위에서 인쇄되어 내려오는 연출은 오버레이일 때 더 강하다 — 시그니처 연출을 우선해 현행(오버레이 + ‘홈으로’)을 추천하고, 사용자 혼선이 관측되면 전체 화면 전환으로 바꾼다.
5-2. 보관
모든 영수증은 기록 탭에 날짜순으로 쌓인다. 놓쳐도 사라지지 않으니 나가는 데 심리적 비용이 없다.

‘오늘은 여기까지’ → ‘영수증 받고 마치기’. 버튼이 무슨 일이 일어날지 그대로 말한다.

사용자 언어 라벨
두 라벨 모두 ‘지금 내 상태’를 말하는 형태로 통일 — “아직이에요”는 이번 세션 안에서 다시 등장, “외웠어요”는 다음 날 이후로 이동.
진행 표시를 세그먼트로
12칸 중 채워진 칸 + “9개 남음”. 남은 양이 개수로 즉시 읽힌다.
남는 과제
FSRS에 Hard/Easy 신호가 없어 초반 간격 추정이 거칠다 → 첫 2주는 보수적 간격으로 시작하고, 필요하면 ‘외웠어요’ 롱프레스에 ‘완전 쉬움’을 숨겨 두는 방식으로 보완 가능.
