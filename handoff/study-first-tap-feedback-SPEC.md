## 핵심 변경 요약
1. 정규 학습 1차에서 **'한 번 익혔어요'·'다시 볼래요'를 처음 누른 직후**, 그 버튼이 어떤 결과를 내는지 애니메이션으로 **버튼별 1회** 보여준다.
2. 학습 전 안내나 버튼 아래 설명문은 쓰지 않는다. UT에서 참여자는 버튼 글자보다 위치·색으로 기억했다("오른쪽 버튼").
3. 익혔어요 = 카드가 **내일 달력**으로 들어감 / 다시 볼래요 = 카드가 **오늘 줄의 맨 뒤**로 감. 글을 읽지 않아도 결과가 보이게 한다.
4. 기존 사용자(이전 '외웠어요' 사용 이력)에게는 업데이트 후 첫 학습에서 버튼 이름 변경을 1회 알린다 (⚠️ O-8).

## 동작 명세
| # | 상황 | 동작 |
|---|---|---|
| 1 | 버튼 탭 | 기존과 같은 카드 전환을 먼저 실행 (익혔어요 = 위로 빠짐, 다시 볼래요 = 아래로 빠짐). 다음 카드가 바로 뒤에 깔림 |
| 2 | 첫 탭이면 | 전환 시작 약 0.3s 뒤 피드백 표시. **표시하는 순간** 해당 버튼의 '봤음'을 저장 (O-2) |
| 3 | 익혔어요 일러스트 (~1.4s) | 미니 카드가 호를 그리며 '내일' 달력으로 이동·축소(0.8s) → 달력 bump(오버슈트) → **라임 체크** badgePop 1회 |
| 4 | 다시 볼래요 일러스트 (~1.4s) | 오늘 줄의 맨 앞 카드가 들려서 맨 뒤로 이동(1.0s), 나머지 카드는 한 칸씩 앞으로 → 맨 뒤 카드에 잉크 테두리 + "↻ 한 번 더" 태그 |
| 5 | 닫기 (바텀시트·센터) | 잉크 CTA '알겠어요' 탭 / 딤 탭(바텀시트) / Esc·뒤로가기. 자동으로 닫히지 않음 |
| 6 | 닫기 (토스트) | 2.4s 뒤 자동 사라짐. 학습을 막지 않음 |
| 7 | 바텀시트 '↻ 다시 보기' | 일러스트만 다시 재생. 기록 변화 없음 |
| 8 | 피드백 표시 중 백그라운드 → 복귀 | 피드백 그대로 유지 |
| 9 | 피드백 표시 중 학습 종료(✕) | 피드백 닫고 종료 확인 흐름으로. '봤음'은 이미 저장됨 |
| 10 | 마지막 카드에서 첫 탭 | 피드백을 닫은 뒤 중간 결과(FirstPassResult)로 이동 |

### 문구 (Draft)
| 대상 | 제목 | 본문 | 토스트 |
|---|---|---|---|
| 익혔어요 | 익힌 단어는 내일 다시 꺼내 볼게요 | 오늘은 한 번 살펴본 것으로 충분해요. 내일 기억나는지 함께 확인해요. | 내일 다시 꺼내 볼게요 |
| 다시 볼래요 | 이 단어는 오늘 한 번 더 나와요 | 단어를 다 본 뒤 다시 보여 드릴게요. 부담 없이 넘어가도 돼요. | 오늘 한 번 더 보여 드릴게요 |
| 이름 변경 (기존 사용자) | 버튼 이름이 바뀌었어요 | 외웠다고 약속하지 않아도 돼요. 한 번 살펴봤다면 '한 번 익혔어요'를 눌러 주세요. | — |

## 상태 · 예외
- 상태 전이 (버튼별 독립): `미표시` → (첫 탭) → `표시 중` → (닫기) → `완료`. `표시 중` 진입 시 이미 `완료`로 저장.
- 저장: 설정 스토어에 `firstTapFeedback: { good: boolean, again: boolean, rename: boolean }`. 백업·복원 대상에 포함 (⚠️ O-2 범위 확인 시 함께).
- 엣지케이스:
  - 빠른 연타: 피드백 표시 중에는 학습 버튼 입력 무시 (딤·오버레이가 막음). 토스트는 막지 않음.
  - 한 세션에서 두 버튼 모두 첫 탭: 각각 한 번씩, 총 2회 표시. 연달아 뜨지 않도록 두 번째는 다음 탭에서만 (이미 그렇게 동작).
  - 12개 모두 같은 버튼: 해당 버튼 피드백 1회만.
- 빈 / 오류 / 로딩: 해당 없음 (로컬 표시만). 마스코트 이미지 로드 실패 시 마스코트 없이 표시.
- 비활성: 학습 버튼 `disabled` 상태(저장 중 등)에서는 피드백도 발생하지 않음.
- 다크 모드: 일러스트 카드·달력은 `canvas`/`soft` 토큰을 따름. 라임 체크는 양 테마 동일(`secondary`).

| O-2 | 노출 횟수 | **버튼별 평생 1회**, 표시 시점에 저장. 기기 로컬 기준 |
| O-3 | 적용 범위 | **정규 학습 1차 버튼만**. 2차 기억 확인·오늘 복습·읽기는 제외 |

| O-6 | 마스코트 | '사장' 라인 마스코트를 원형 흰 배경 위에 작게. 대사 말풍선은 쓰지 않음 |
| O-7 | 형태 | ⚠️ 확인 필요 — 바텀시트 / 센터(토스형, 블러 배경 + 큰 일러스트) / 토스트 중 시안 비교 후 결정. 제안: 첫 탭은 **센터 또는 바텀시트**(토스트는 안 읽고 지나갈 위험이 UT 결과와 같음) |
| O-8 | 기존 사용자 | ⚠️ 확인 필요 — 이름 변경 안내 + 첫 탭 피드백 둘 다 보여주면 모달이 최대 3회. 안내 1회로 대체할지 결정 |
| O-9 | 카드 탭 뜻 보기 힌트 | ⚠️ 확인 필요 — UT-2J7YU5가 두 번째 체험에서야 발견. 첫 카드에 힌트를 넣을지, 별도 과제로 뺄지 |
| O-10 | UT 측정 | ⚠️ 확인 필요 — 다음 UT에서 이 피드백을 B에 넣으면 문구 효과와 안내 효과가 섞임. 버전 정의(예: B / B+피드백) 결정 |
