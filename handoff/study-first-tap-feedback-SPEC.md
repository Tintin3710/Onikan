## 핵심 변경 요약
1. 정규 학습 1차에서 **'한 번 익혔어요'·'다시 볼래요'를 처음 누른 직후**, 그 버튼이 어떤 결과를 내는지 애니메이션으로 **버튼별 1회** 보여준다.
2. 학습 전 안내나 버튼 아래 설명문은 쓰지 않는다. UT에서 참여자는 버튼 글자보다 위치·색으로 기억했다("오른쪽 버튼").
3. 익혔어요 = 카드가 **'며칠 뒤' 달력**으로 들어감 / 다시 볼래요 = 카드가 **오늘 줄의 맨 뒤**로 감. 글을 읽지 않아도 결과가 보이게 한다.
4. 형태(2026-11-13 개정 O-17): **'한 번 익혔어요' 첫 경험 = 신규·기존 모두 바텀시트 1회.** 기존 사용자도 이 버튼 자체가 처음이라 뜻을 모르기 때문. '다시 볼래요'만 기존 사용자 토스트 1회(O-8), '익혔어요' 토스트는 폐기. 이전 빌드에서 이미 토스트를 본 사용자에게는 시트를 다시 띄우지 않는다.

- 하루 학습 = **오늘 날짜가 된 복습 + 신규, 합계 최대 36개** (2026-11-10 변경; 설정을 36보다 높이면 설정값까지). 넘치는 복습은 오래 밀린 것부터 내고 나머지는 다음 날로.
- 신규 수 = `min(하루 신규 설정, min(설정×3, max(36, 설정)) − 오늘 복습 수)`. 3일 이상 쉬고 돌아오면 학습일 3일간 신규 절반 보장. 입문자는 목표 기억률 0.85.
- 같은 단어가 다시 나오는 간격은 맞힐수록 길어지므로, 며칠 전 단어를 일부러 빼는 규칙은 없다.

## 상태 · 예외
- 상태 전이 (버튼별 독립): `미표시` → (첫 탭) → `표시 중` → (닫기) → `완료`. `표시 중` 진입 시 이미 `완료`로 저장.
- 저장: 설정 스토어에 `firstTapFeedback: { cohort: 'new' | 'existing', good: boolean, again: boolean, toast: boolean }` (`cohort` = O-12 판정 결과, 신규 = good·again, 기존 = toast만 사용). 백업·복원 대상에 포함 (복원한 기기에서 다시 뜨지 않게). 복원한 백업에 학습 기록이 있으면 `cohort`도 백업 값을 따른다. *(2026-11-11 구현 메모: 앱에는 아직 백업 **내보내기**만 있고 복원 기능이 없어, 이 플래그는 기기 설정(AsyncStorage)에만 저장한다. 복원 기능을 만들 때 함께 넣는다.)*
- 엣지케이스:
  - 빠른 연타: 바텀시트 표시 중에는 학습 버튼 입력 무시 (딤이 막음). 토스트는 막지 않음 — 토스트 중 다음 탭이 와도 새 토스트 없음.
  - 한 세션에서 두 버튼 모두 첫 탭: 각각 한 번씩, 총 2회 표시. 연달아 뜨지 않도록 두 번째는 다음 탭에서만 (이미 그렇게 동작).
  - 12개 모두 같은 버튼: 해당 버튼 피드백 1회만.
- 빈 / 오류 / 로딩: 해당 없음 (로컬 표시만). 마스코트 이미지 로드 실패 시 마스코트 없이 표시.
- 비활성: 학습 버튼 `disabled` 상태(저장 중 등)에서는 피드백도 발생하지 않음.
- 다크 모드: 일러스트 카드·달력은 `canvas`/`soft` 토큰을 따름. 라임 체크는 양 테마 동일(`secondary`).
