## 핵심 변경 요약
1. 홈은 **가게 그림 한 장 + 사장님 한마디 + 버튼 하나**만 둔다. 오늘 상태(시작 전·진행 중·완성·쉬는 날)는 글자 대신 **가게 모습**이 보여 준다.
2. 첫 실행만 인트로 풀 시퀀스 F(노렌 낙하 → 앞발 → 빼꼼 → 도장)를 보여 주고, 그다음부터는 **정지 장면 + 탭할 때 최소 모션**(노렌 걷힘 180ms)만 쓴다.
3. 지난 기록은 기록 탭의 "지나온 골목"(작은 가게 줄), 레벨은 "가게가 자란다"(포장마차 → 가게)로 옮긴다.
4. 새 그림은 **가게 외관 한 벌을 레이어로 나눠서** 상태마다 켜고 끄는 방식으로 줄인다. 인트로 레이어 11종은 그대로 다시 쓴다.

## 공통 규칙

| 항목 | 규칙 |
|---|---|
| 형식 | PNG, 투명 배경, @3x. 개발은 Reanimated + 레이어 PNG로 겹친다(인트로 O-7과 같음, v1에서 Rive·Lottie 안 씀) |
| 가게 아트보드 | **모든 SHOP 레이어는 같은 아트보드(1080×930 @3x = 360×310pt)** 위 제자리에 놓고 내보낸다. 개발은 `absoluteFill`로 겹치기만 한다 |
| 피벗 | 움직이는 레이어(노렌, 김, 등불 빛, 사장님)는 아트보드 기준 피벗 좌표를 같이 준다 |
| 색 | 노렌 주황은 브랜드 `#FF902F` 계열, 바탕은 `#F6F5EF` 위에서 보이도록. 라임은 쓰지 않는다 |
| 선·질감 | 고양이 드로잉과 같은 선 두께·질감. 가게도 "그린 그림"이어야 하고 벡터 아이콘 느낌이면 안 된다 |
| 다크 모드 | 일러스트는 고정색(인트로와 같음). 등불 켜짐은 다크에서도 그대로 |
