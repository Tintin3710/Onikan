## 조건
- 설정 하루 새 단어 12, 매일 오전 9시 학습, 60일. 쉼 = 15일차부터 3일 / 7일 학습 안 함.
- 일반 사용자: 처음 만난 단어 '다시 볼래요' 15%, 복습 정답 확률 = FSRS 예측 기억률.
- 이전 정책(v1.0.6 전): 상한 없음 — 복습 전부 + 신규 `min(12, 36 − 복습)`.
- 무작위 시드 30개, 숫자는 **중앙값**(괄호는 최소–최대).

## 읽는 법
- **포폴에 쓸 숫자:** "7일 쉬고 돌아온 날 124개(새 단어 0) → 36개(복습 30 + 새 단어 6)". 11-10 시뮬레이션(124)과 출시 코드 재현(124.5)이 일치한다.
- 11-10과 다른 숫자: 3일 쉼 74 → 85, 매일 최대 68 → 53. 11-10은 단일 실행이고 이번은 시드 30개 중앙값이라 생기는 차이. 포폴에는 두 번 모두 확인된 7일 쉼 숫자만 쓴다.
- **트레이드오프 (숨기지 않기):** 이전 정책은 돌아온 날 하루에 몰아서 끝내고 사흘째부터 새 단어 12개로 돌아온다. 출시 정책은 부담을 1주로 나누는 대신, 7일 쉰 사람은 **복귀 4일째부터 밀린 복습이 끝날 때까지 새 단어 0**이 된다(스펙 "복귀 3일 뒤 밀림이 남음 → 복습 우선"과 일치). 데이터 수집이 생기면 복귀 4~7일차 이탈을 함께 본다.
